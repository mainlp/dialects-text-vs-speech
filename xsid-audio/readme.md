# Metadata files for xsid-audio

These TSV files contain mappings between the sentences, intents, and audio files.
For the audio files, see https://zenodo.org/records/19554428.

Contains the mapping of all xSID dev/test sentences (CC BY-SA 4.0) to intents and to the audio files in https://zenodo.org/records/19554428. Except for `xsid_de-ba_test.tsv`, these files are identical to the metadata files on Zenodo. **xsid_de-ba_test.tsv fixes an issue with misaligned sentence IDs in the Bavarian data in the Zenodo metadata files.**
